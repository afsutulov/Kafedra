# ПК «Кафедра» — система управления обучением (LMS)

Программный комплекс для ИТ-университета: личные кабинеты учащегося, преподавателя и администратора, учебные материалы, тестирование, задания, журнал, рейтинги, расписание, портфолио.

Правообладатель и автор — ООО «Рога и копыта». Название продукта и правообладатель выводятся в нижней строке интерфейса и не настраиваются. Название портала, название организации и логотип в заголовке задаются в `config.json` (`portal_name`, `org_name`, `logo_file`) — продукт подходит и вузам, и коммерческим организациям.

## Главное

| | |
|---|---|
| Язык | Go 1.24, **только стандартная библиотека** — ни одного стороннего модуля (`go.mod` без зависимостей) |
| Поставка | один статический исполняемый файл (≈10 МБ), веб-интерфейс встроен внутрь |
| Хранилище | собственное встраиваемое документное хранилище на JSON (журнал + снимки), **без SQL и без внешней СУБД** |
| Развёртывание | без контейнеров; `sh deploy/install.sh` — служба systemd за одну команду |
| Интерфейс | собственные HTML/CSS/JS, плоское оформление в серо-синей гамме; без фреймворков и внешних ресурсов (CDN, шрифты, счётчики) |
| Без сертификатов | работает по HTTP за общим веб-сервером с HTTPS (`tls_cert`/`tls_key` пустые, `external_url`) |
| Закрытый контур | полностью работает без выхода в интернет, включая двухфакторный вход |
| Настройки | один читаемый файл `config.json`; данные — читаемый `snapshot.json` |
| Размещение | всё в одном каталоге `/opt/kafedra` (программа, конфигурация, сертификат, данные); журнал — `/var/log/kafedra` |
| ОС | Linux x86-64 и ARM64 (Astra Linux, РЕД ОС, Альт и др.); зависимостей от пакетов ОС нет |

## Быстрый старт (пробный запуск за минуту)

```sh
K=./dist/kafedra-linux-amd64
$K init  -config ./config.json -data ./data -log - -listen 127.0.0.1:8080 -demo   # всё в текущем каталоге
$K serve -config ./config.json                                                     # http://127.0.0.1:8080
```

Без параметра `-config` программа работает с каталогом по умолчанию `/opt/kafedra` (см. ниже). Команда `init` один раз печатает временные пароли. При первом входе каждый пользователь задаёт свой пароль и даёт согласие на обработку персональных данных. Двухфакторный вход (TOTP) поддерживается, но по умолчанию необязателен.

Промышленная установка: `sudo sh deploy/install.sh lms.example.ru "Название организации" "Название портала"` — см. `docs/02-ustanovka-i-ekspluataciya.md`.

## Сборка из исходных текстов

```sh
sh build.sh        # go vet, тесты, сборка dist/kafedra-linux-{amd64,arm64}, SHA256SUMS
```

Сеть для сборки не нужна (`GOPROXY=off`).

## Состав

```
cmd/kafedra/        точка входа и команды (init, serve, backup, restore, passwd, audit-verify, gencert)
internal/store/     документное хранилище JSON: журнал упреждающей записи, снимки, блокировка каталога
internal/secure/    пароли (PBKDF2 + ключ-«перец»), ключи, TOTP, AES-GCM, журнал событий с цепочкой хешей
internal/content/   преобразователь Markdown → безопасный HTML, импорт DOCX
internal/app/       прикладная логика, маршруты, шаблоны страниц, стили, сценарии
deploy/             install.sh, модуль systemd
docs/               документация (в том числе комплект для реестра российского ПО)
dist/               готовые исполняемые файлы и контрольные суммы
```
