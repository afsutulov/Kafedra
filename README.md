# ПК «Кафедра» — система управления обучением (LMS)

Программный комплекс для ИТ-университета: личные кабинеты учащегося, преподавателя и администратора, учебные материалы, тестирование, задания, журнал, рейтинги, расписание, портфолио.

> «Кафедра» — рабочее название. Название системы и организации задаются в конфигурации (`system_name`, `org_name`); перед регистрацией проверьте название на совпадение с чужими товарными знаками.

## Главное

| | |
|---|---|
| Язык | Go 1.24, **только стандартная библиотека** — ни одного стороннего модуля (`go.mod` без зависимостей) |
| Поставка | один статический исполняемый файл (≈10 МБ), веб-интерфейс встроен внутрь |
| Хранилище | собственное встраиваемое документное хранилище на JSON (журнал + снимки), **без SQL и без внешней СУБД** |
| Развёртывание | без контейнеров; `sh deploy/install.sh` — служба systemd за одну команду |
| Интерфейс | собственные HTML/CSS/JS в стилистике АСИМ, без фреймворков и внешних ресурсов (CDN, шрифты, счётчики) |
| ОС | Linux x86-64 и ARM64 (Astra Linux, РЕД ОС, Альт и др.); зависимостей от пакетов ОС нет |

## Быстрый старт (пробный запуск за минуту)

```sh
./dist/kafedra-linux-amd64 init -listen 127.0.0.1:8080 -demo   # создаёт config.json, ./data, администратора и демо-данные
./dist/kafedra-linux-amd64 serve                               # http://127.0.0.1:8080
```

Команда `init` один раз печатает временные пароли. При первом входе каждый пользователь задаёт свой пароль и даёт согласие на обработку персональных данных; администратор дополнительно подключает второй фактор (TOTP).

Промышленная установка: `sudo sh deploy/install.sh lms.example.edu "Название вуза"` — см. `docs/02-ustanovka-i-ekspluataciya.md`.

## Сборка из исходных текстов

```sh
sh build.sh        # go vet, тесты, сборка dist/kafedra-linux-{amd64,arm64}, SHA256SUMS
```

Сеть для сборки не нужна (`GOPROXY=off`).

## Состав

```
cmd/kafedra/        точка входа и команды (init, serve, backup, restore, passwd, audit-verify, gencert)
internal/store/     документное хранилище JSON: журнал упреждающей записи, снимки, блокировка каталога
internal/secure/    пароли (PBKDF2 + ключ-«перец»), ключи, TOTP, AES-GCM, журнал событий с цепочкой хешей
internal/content/   преобразователь Markdown → безопасный HTML, импорт DOCX
internal/app/       прикладная логика, маршруты, шаблоны страниц, стили, сценарии
deploy/             install.sh, модуль systemd
docs/               документация (в том числе комплект для реестра российского ПО)
dist/               готовые исполняемые файлы и контрольные суммы
```
