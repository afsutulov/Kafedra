# Руководство пользователя

## Общее

**Вход.** Откройте адрес системы, введите логин и пароль. При первом входе задайте собственный пароль и подтвердите согласие на обработку персональных данных. После нескольких неверных попыток учётная запись временно блокируется.

**Пароль.** Значок «глаз» в поле ввода показывает и скрывает введённые символы.

**Кнопка «Вверх»** появляется при прокрутке и возвращает в начало страницы.

**Профиль.** Смена пароля, подключение двухфакторной аутентификации (любое приложение-аутентификатор стандарта TOTP: добавьте учётную запись вручную по показанному ключу), список и завершение своих сеансов.

**«Аа»** в шапке — версия для слабовидящих. **Уведомления** — оценки, сданные работы, аннулированные попытки.

## Преподавателю

### Курс
«Мои курсы» → «Создать курс» (если разрешено администратором) либо курс назначает администратор. В «Настройках курса» укажите описание и группы. Разделы (модули) — внизу вкладки «Материалы».

### Как добавить группу учащихся из Excel
Курс → вкладка «Участники» → «Добавить группу учащихся из Excel».
1. Скачайте шаблон. Обязательные столбцы: **Email, Фамилия, Имя**; Отчество — при наличии; Роль — «Учащийся» (преподаватель курса добавляет только учащихся).
2. Введите название группы, выберите заполненный файл, нажмите «Создать учётные записи».
3. Скачается файл результата: по каждой строке — логин, временный пароль либо причина ошибки (не заполнено обязательное поле, неверный формат адреса, адрес повторяется в файле или уже используется). Раздайте пароли и удалите файл.

Новая группа создаётся и назначается курсу автоматически. Пополнить можно только группу, уже назначенную этому курсу; существующую группу к курсу подключает администратор.

### Анкеты и доступ к обучению
Если включена анкета перед началом обучения, во вкладке «Участники» у каждого учащегося виден статус: «анкета не отправлена», «отправлена» (учащийся отметил отправку) или «доступ открыт». Администратор проверяет анкету и открывает доступ: в карточке учащегося либо во вкладке «Участники» курса — по одному или кнопкой «Открыть доступ всем, кто отметил отправку анкеты». Преподаватель видит статусы, но доступ не открывает.

### Отправка сертификата по почте
Если почта настроена, во вкладке «Участники» у выданного сертификата показано состояние письма: отправлено, в очереди, не отправлено. Кнопка «Отправить» ставит письмо в очередь заново на текущий адрес из профиля учащегося — после неудачи, после исправления адреса или для сертификата, выданного до настройки почты. Такая же кнопка есть у учащегося на странице курса.

### Аналитика и экспорт результатов
Курс → вкладка «Аналитика». Выберите группу, период и тест (или «Курс в целом»), нажмите «Показать». Кнопка **«Экспорт (XLSX)»** выгружает таблицу с теми же отборами: ФИО, Email, группа, набранные баллы, максимальный балл, процент выполнения, статус.

### Общение (чаты)
Пункт меню «Общение»: чаты ваших курсов и групп. Вы — модератор: можете удалить любое сообщение и исключить участника («Участники и модерация»); исключённый не видит чат и не может в него писать, вернуть его можно там же. К сообщению можно приложить изображение (JPG, PNG), PDF или DOCX.

### Как разместить материал

В нужном разделе выберите вид, введите название, нажмите «Добавить». Материал создаётся **черновиком**; учащиеся увидят его после отметки «Опубликовано».

| У вас есть | Что делать |
|---|---|
| Лекция в Word | вид «Лекция» → «Импорт из документа Word» → выберите .docx → «Сохранить и посмотреть». Текст можно править прямо в редакторе |
| PDF, презентация, видео | вид «Файл» (один файл на страницу) либо вложение к лекции. PDF, MP4/WebM, изображения и аудио открываются прямо в браузере |
| Ничего готового | вид «Лекция», пишите в редакторе; кнопки панели вставляют разметку |
| Исходный код, архивы | вложение — учащиеся скачают |

Рекомендация: текст — страницей (читается с телефона, индексируется, правится за минуту), слайды — PDF, записи занятий — MP4 (H.264). PPTX/DOCX как вложения доступны только для скачивания.

Рисунок внутри текста: прикрепите изображение, сохраните, затем в списке вложений нажмите «В текст».

Разметка: `# Заголовок`, `**жирный**`, `*курсив*`, `- пункт`, `1. пункт`, `` `код` ``, блок кода между строками из трёх обратных апострофов (после них можно указать язык), таблицы через `|`, `> цитата`, `[текст](https://адрес)`.

### Тест
1. Вид «Тест» → параметры: баллы в журнал, время, попытки, окно доступности, порог зачёта, число вопросов в попытке (случайная выборка из банка).
2. Вопросы — формой «Новый вопрос» или «Быстрый ввод»:

```
? Какой протокол работает на транспортном уровне?
+ TCP
- HTTP
- IP

? Отметьте компилируемые языки
+ Go
+ C++
- Python
* 2

? Сколько бит в байте?
= 8
= восемь
```
`?` вопрос, `+` верный вариант, `-` неверный, `=` допустимый ответ при вводе, `* N` баллы. Тип определяется автоматически.

Третий способ — **«Загрузить вопросы из Excel»**: скачайте шаблон, заполните (вопрос, баллы, номер правильного варианта или допустимые ответы, варианты), загрузите. Если в файле есть ошибки, не загружается ни один вопрос, а на экране появляется протокол: лист, строка, тип ошибки и описание — по всем ошибкам сразу.

Параметр **«Скрывать баллы во время прохождения»**: учащийся видит только «Вопрос N из M»; баллы за вопросы и итог показываются на экране результатов.

3. Отметьте «Опубликовано». Тест без вопросов опубликовать нельзя.
4. «Результаты»: баллы, просмотр попыток, **аннулирование** (даёт учащемуся новую попытку), анализ вопросов.

Максимум баллов теста после первой попытки изменить нельзя (создайте новый тест): результаты уже сданных попыток фиксируются. 

В журнал идёт лучшая попытка. За вопрос с несколькими ответами начисляется доля баллов: (верные − неверные) / число верных.

### Задание
Вид «Задание» → условие, максимальный балл, срок. На странице задания — работы всех учащихся: текст, файл, поля «баллы» и «комментарий». Оценку можно изменить. До выставления оценки учащийся может отправить работу заново.

### Журнал
Вкладка «Журнал» курса. Тесты и задания заполняются автоматически. Для семинаров, коллоквиумов, активности добавьте столбец («Столбцы журнала»), введите баллы, «Сохранить оценки». «Выгрузить в Excel» — таблица результатов выбранной группы (.xlsx); «CSV» — то же в текстовом виде.

### Расписание и посещаемость
«Расписание» → «Добавить занятие»: курс и группа, вид, дата, время, аудитория, число недель повтора. Пересекающиеся занятия не создаются. «Посещаемость» у занятия — отметки по списку группы.

### Объявления и обсуждение
Вкладки курса. Объявления видны на главной странице учащихся.

## Учащемуся

- **Анкета.** Если организация требует анкету, после первого входа откроется страница «Анкета слушателя»: скачайте анкету, заполните, отправьте на указанный адрес и нажмите «Анкета отправлена». Материалы откроются после проверки — придёт уведомление.
- **Получение документов.** Когда выполнены все обязательные задания курса, на странице курса появляется блок «Получение документов»: скачайте заявление, распечатайте, подпишите, загрузите скан или фотографию. Если заявление обязательно, дождитесь сверки у преподавателя. Затем нажмите «Получить сертификат (PDF)». Если в организации настроена почта, сертификат также придёт на адрес из вашего профиля.
- **Общение.** Чаты вашей группы и ваших курсов; можно приложить изображение, PDF или DOCX.
- **Главная** — ближайшие сроки, курсы с прогрессом, занятия на неделю, объявления.
- **Мои курсы** — материалы по разделам; изученные отмечаются автоматически.
- **Тест** — «Начать тест». Время идёт на сервере и не останавливается при закрытии страницы; ответы, отправленные не позже 30 секунд после окончания времени, принимаются; ответы сохраняются автоматически; по истечении времени тест завершается сам.
- **Задание** — введите ответ и/или приложите файл, «Отправить на проверку». До оценки можно отправить заново.
- **Оценки** — баллы по всем контрольным точкам, итог, текущая оценка, посещаемость.
- **Рейтинг** — ваше место в группе.
- **Расписание** — неделя; «Календарь (.ics)» — файл для импорта в календарь телефона.
- **Портфолио** — добавляйте проекты, сертификаты, публикации; оценённые работы попадают автоматически. Портфолио видят ваши преподаватели и администратор.
