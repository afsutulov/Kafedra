## 2. Разработка

- Исходные тексты — на языке Go; хранятся в системе контроля версий на инфраструктуре правообладателя в РФ: `<репозиторий>`.
- Сборка воспроизводима и автономна: `sh build.sh` (без доступа в сеть, сторонние модули отсутствуют). Средства сборки — инструментарий Go 1.24+.
- Версии: `ОСНОВНАЯ.МЛАДШАЯ.ИСПРАВЛЕНИЕ`. Номер вшивается в исполняемый файл и отображается в интерфейсе.

### Безопасная разработка (ориентир — ГОСТ Р 56939-2024)

| Практика | Реализация |
|---|---|
| Статический анализ | `go vet` при каждой сборке |
| Модульное и сквозное тестирование | `go test ./...` — хранилище, криптография, разметка, импорт DOCX, сквозной сценарий с проверкой разграничения доступа |
| Поиск гонок | `go test -race` |
| Фаззинг-тестирование разборщиков недоверенных данных | `go test -fuzz FuzzRender`, `-fuzz FuzzImportDOCX` (`internal/content`) |
| Контроль заимствованных компонентов | сторонних компонентов нет; перечень — `docs/06-reestr-po.md` |
| Контроль целостности поставки | `dist/SHA256SUMS`; сумма отображается в разделе «Система» и пишется в журнал событий при запуске |
| Устранение уязвимостей | регламент в разделе 4 |
