# Описание функциональных характеристик ПК «Кафедра»

Версия 1.4.4. Правообладатель: ГБУ ПК «Центр информационного развития ПК»

## 1. Назначение

ПК «Кафедра» — система управления обучением (LMS) для образовательных и коммерческих организаций (вуз, учебный центр, корпоративный университет). Обеспечивает размещение и изучение учебных материалов, тестирование, приём и проверку работ, ведение электронного журнала и расписания, расчёт рейтингов, электронное портфолио и администрирование. Устанавливается на один сервер организации; пользователи работают через браузер.

## 2. Роли

| Роль | Возможности |
|---|---|
| Учащийся | изучение материалов своих курсов, тесты, сдача заданий, просмотр оценок, рейтинга, расписания, обсуждения, портфолио |
| Преподаватель | создание и наполнение курсов, тесты и задания, проверка работ, журнал, посещаемость, расписание, объявления |
| Администратор | учётные записи, группы, назначение преподавателей и групп на курсы, настройки безопасности, журнал событий, резервные копии |

## 3. Функции

### 3.1. Курсы и материалы
- Курс (дисциплина) с описанием, разделами (модулями), преподавателями и учебными группами.
- Элементы курса четырёх видов: **лекция** (страница), **файл**, **тест**, **задание**; порядок, черновик/опубликовано.
- Лекция: текст в разметке Markdown (заголовки, списки, таблицы, блоки кода, цитаты, ссылки, рисунки), панель форматирования.
- **Импорт из Word (.docx)** в редактируемый текст с переносом заголовков, списков, таблиц, выделения, ссылок и рисунков; импорт .md и .txt.
- Вложения: PDF, изображения, видео MP4/WebM и аудио открываются прямо на странице; прочие форматы (презентации, архивы, исходный код) скачиваются.
- Отметка изучения и индикатор прохождения курса; переходы «назад / далее».

### 3.2. Тестирование
- Вопросы: один правильный ответ, несколько (с частичным зачётом и штрафом за неверные варианты), ввод ответа.
- Параметры: ограничение времени, число попыток, окно доступности, перемешивание вопросов и вариантов, случайная выборка из банка, порог зачёта, показ разбора.
- Быстрый ввод вопросов текстом (`?`, `+`, `-`, `=`, `*`) и **загрузка вопросов из шаблона Excel**; при ошибках в файле выводится протокол: лист, строка, тип ошибки.
- Параметр теста «Скрывать баллы во время прохождения»: учащийся видит только «Вопрос N из M», баллы — на экране результатов.
- Отсчёт времени ведётся на сервере; ответы автоматически сохраняются каждые 20 секунд; по истечении времени попытка завершается автоматически.
- Результаты: таблица по учащимся, просмотр и аннулирование попыток, анализ вопросов (доля верных ответов).

### 3.3. Задания
- Условие, вложения, максимальный балл, срок сдачи.
- Учащийся отправляет текст и/или файл; сдача после срока помечается.
- Преподаватель выставляет баллы и комментарий; учащийся получает уведомление.

### 3.4. Журнал, оценки, рейтинг
- Журнал курса по группам: баллы за тесты (лучшая попытка) и задания подставляются автоматически, ручные столбцы (семинары, коллоквиумы) заполняет преподаватель.
- Итог, процент, оценка по настраиваемой шкале; сводка посещаемости; выгрузка по группе в Excel (.xlsx) и CSV.
- **Раздел «Аналитика» курса**: результаты учащихся с отбором по группе, периоду и конкретному тесту; кнопка «Экспорт» формирует XLSX (ФИО, Email, группа, набранные баллы, максимальный балл, процент выполнения, статус «Пройдено / Не пройдено»).
- Учащийся видит свои оценки по всем курсам.
- Рейтинг по курсу, группе или всем курсам; по умолчанию учащийся видит только собственное место (ФИО остальных скрыты).

### 3.5. Расписание и посещаемость
- Занятия (лекция, практика, лабораторная, семинар, консультация, экзамен) с аудиторией, еженедельным повтором и проверкой пересечений по группе, преподавателю и аудитории.
- Недельное представление; экспорт в календарь (iCalendar, .ics).
- Отметка посещаемости по каждому занятию.

### 3.6. Взаимодействие
- Объявления курса и общесистемные; персональные уведомления.
- **Раздел «Общение»**: групповые чаты по курсу и по учебной группе с автообновлением ленты. Вложения — изображения JPG/PNG, PDF, DOCX с ограничением размера; исполняемые и прочие файлы отклоняются. Преподаватель-модератор удаляет сообщения и исключает участников.
- Электронное портфолио учащегося: собственные записи с файлами и автоматически собираемый перечень оценённых работ.

### 3.6а. Анкета, заявление и сертификат
- **Анкета перед началом обучения** (включается настройкой): до проверки анкеты учащийся не допускается к материалам. Он скачивает анкету (PDF или .docx), отправляет её на указанный адрес электронной почты и отмечает «Анкета отправлена»; доступ после проверки открывает администратор.
- Бланк согласия на обработку персональных данных (.docx).
- После выполнения всех обязательных заданий курса (материалы изучены, тесты сданы на зачёт, задания проверены) появляется блок **«Получение документов»**: заявление на сертификат (PDF или .docx), форма загрузки скана или фотографии подписанного заявления, сверка преподавателем и получение сертификата.
- **Сертификат** (PDF): значок, организация, курс, ФИО учащегося и преподавателя, дата, идентификатор. Выданный файл сохраняется в системе и не меняется. Если задан почтовый сервер, сертификат автоматически отправляется на адрес из профиля учащегося.

### 3.7. Администрирование
- **Импорт пользователей из шаблона** (XLSX или CSV в кодировке UTF-8 либо Windows-1251): Email, Фамилия, Имя, Отчество, Роль. Проверяются обязательные поля, формат и повторы адресов. Администратор загружает учащихся и преподавателей; преподаватель курса — группу учащихся своего курса (отключается настройкой).
- Учётные записи: создание, импорт из CSV, отключение, сброс пароля и второго фактора, удаление вместе с персональными данными.
- Группы; настройки парольной политики, сеансов, шкалы оценок, файлов.
- Журнал событий безопасности с проверкой целостности; активные сеансы; резервное копирование и восстановление.

### 3.8. Доступность
- Адаптивная вёрстка (телефон, планшет, ПК); версия для слабовидящих (кнопка «Аа»); показ вводимого пароля; кнопка «Вверх»; работа с клавиатуры; версия для печати.

## 4. Технические характеристики

| Параметр | Значение |
|---|---|
| Серверная ОС | Linux, ядро 3.2+; x86-64, ARM64 |
| Зависимости | отсутствуют (статический исполняемый файл) |
| СУБД | не требуется (встроенное хранилище) |
| Клиент | современный браузер (Яндекс Браузер, Chromium, Firefox, Safari), установка ПО не требуется |
| Протокол | HTTPS (TLS 1.2+) собственными средствами либо HTTP за общим веб-сервером с HTTPS |
| Сеть | выход в интернет не требуется ни серверу, ни рабочим местам |
| Ресурсы (до ~2 000 пользователей) | 2 ядра, 2 ГБ ОЗУ, диск по объёму материалов |
| Язык интерфейса | русский |
