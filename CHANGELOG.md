# История изменений ПК «Кафедра»

## 1.4.4
- Вход: по адресу считаются только неудачные попытки (`login_failures_per_address`, по умолчанию 100 за 10 минут); раньше 21-й пользователь с одного адреса не мог войти.
- Смена пароля больше не задерживает сохранение ответов и сдачу тестов у остальных пользователей.
- Одновременных вычислений хеша пароля — не больше «число ядер − 1».
- Предупреждения при запуске: не задан `trusted_proxy` при работе за веб-сервером; не задан `org_name`.
- Учащийся сразу видит, что сертификат не выдаётся из-за незаполненной организации или отсутствия преподавателя.
- Значок сайта для вкладки с PDF; таблица «Участники» помещается по ширине.

## 1.4.3
- Устранена гонка данных при изменении настроек.
- Прогресс, аналитика и условия выдачи сертификата используют общие критерии: проваленный тест и непроверенное задание не считаются выполненными.
- Максимум баллов задания нельзя менять после оценивания работ.
- Таймер теста работает при нулевом остатке времени; текстовый ответ ограничивается 500 символами, а не байтами.
- Неполные резервные копии не вытесняют исправные; копирование журнала событий не задерживает запись.
- Редактор вопросов сообщает об отказе хранилища; чат не вставляет страницу входа в ленту.
- Повторная отправка сертификата после смены адреса; ускорены аналитика и чат.

## 1.4.2
- Импорт теста из XLSX: формула ниже таблицы даёт протокол ошибок, а не ошибку 500.
- Импорт пользователей из CSV в кодировке Windows-1251.
- PDF со служебными байтами после конца файла принимается.
- Администратор открывает доступ после анкеты сразу группе учащихся.
- Повторная отправка письма с сертификатом; параметр `smtp_allow_plain`.

## 1.4.1
- Доступ после анкеты открывает администратор; преподаватель подтверждает сверку скана заявления.
- Очередь отправки сертификатов с повторами; TLS на порту 465.
- Шаблон пользователей в CSV; проверка содержимого вложений; уточнения аналитики.

## 1.4.0
- Импорт пользователей из шаблона, раздел «Аналитика» с экспортом, раздел «Общение».
- Анкета перед началом обучения, блок «Получение документов», отправка сертификата по почте.
- Параметр теста «Скрывать баллы во время прохождения», протокол ошибок импорта теста.
